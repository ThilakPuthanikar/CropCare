CropCare - How to Run

1. Open PowerShell or Terminal in the main folder (d:\Project\CropCare).

2. Run the automated launcher:
   .\start.bat

   (This automatically checks your virtual environment, installs dependencies, launches the FastAPI server connected to Neon PostgreSQL, opens your browser at http://127.0.0.1:8000, and manages Ngrok tunneling.)

3. To stop all running services:
   .\stop.bat
